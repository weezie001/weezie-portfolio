A good place
to start.

This kit gives you a finished fictional identity and editable applications, alongside the documents you need to run a real client job.

1. Explore the complete example.

  • Open the template editor. It works directly from the extracted folder, with no installation.
  • Read the sample brand guidelines.
  • Review the exact-size stationery proofs.

2. Build the client's version.

Duplicate the folder for the client. In the editor, choose Blank, set the brand name, colors, type and contact details, and add an approved client image. Save the settings as JSON so you can load them again.

Export a single SVG, the full branded SVG pack, or the editable HTML book. The full SVG export also contains logo variants, CSS and JSON design tokens, an email signature and a readme. Images are embedded in exported artwork.

3. Finish the design.

Open SVG artwork in a vector editor such as Inkscape or Illustrator. Edit text, replace the sample mark with the approved client logo, and review the layout. Figma can import SVG artwork; text editability depends on the import behavior and installed fonts. Native Figma and Canva files are not included.

The editor changes brand details and imagery. It does not invent a new logo or brand strategy. Rewrite the sample positioning, voice, copy, invoice amounts and dates for the real job. Edit the HTML brand book in a text editor, or use its Toggle text editing button and save the modified page from your browser.

4. Send a useful handover.

  • Keep the final logo SVGs and approved PNG exports together.
  • Include the final brand book, agreed applications and matching web tokens.
  • Open the edited HTML book and use Print / save as PDF to produce the client's PDF.
  • Use the delivery checklist and walkthrough guide before sending.
  • Leave studio process documents and unapproved explorations out of the client handover.

Email signatures and print files.

The sample HTML signature previews with a local logo. For a real signature, host the final PNG at a public HTTPS address, update its src, then copy the rendered signature into the email application's signature editor. Keep the logo small and test it in the mail clients the customer uses.

Business-card SVGs are designed at 85 × 55 mm proportions. The stationery proof PDF includes 3 mm bleed around both cards. A4 pages are 210 × 297 mm. Social and presentation files use pixel dimensions. Always confirm print color conversion, trim, fonts and a proof with the printer.

Atelier North is fictional. The workshop image is original AI-generated sample imagery. Fonts are referenced, not bundled. Your client's logo and imagery need their own approval.
