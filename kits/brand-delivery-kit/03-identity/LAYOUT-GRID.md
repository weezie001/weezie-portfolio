## Grid

- Desktop: 12 column, max width `[1120–1280]`, gutter `[24]`, margin `[40]`
- Tablet: 8 column
- Mobile: 4 column, gutter 16, margin 20

## Radius

| Token | px | Use |
|---|---|---|
| r-sm | | inputs |
| r-md | | cards |
| r-lg | | hero media |
| r-full | 999 | pills / avatars |

Pick a personality: sharp (2–4) vs soft (16–28). Do not mix both.

## Elevation / tactile

If the site is neumorphic / paper, document:

- Light source
- Shadow light colour + shadow dark colour
- Border policy (1px line vs shadow-only)

If the site is flat / luxury: almost no shadow, hairline borders.

## Content width

Body text measure, pull quotes, captions.
