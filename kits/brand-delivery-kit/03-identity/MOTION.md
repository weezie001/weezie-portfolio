# Motion

Even a static brand needs a motion *policy* so the website and ads do not feel like two companies.

## Principles

- Duration: UI 150–250ms, page 400–700ms, cinematic only if sold
- Easing: `[example: cubic-bezier(0.22, 1, 0.36, 1)]`
- Distance: small (8–16px), never flying from off-screen on every card

## Logo

- Intro: `[none / fade / slight scale 0.98→1]`
- Looping logo marks: no (unless a loading spinner is designed)

## UI

| Event | Motion |
|---|---|
| Button hover | |
| Page enter | |
| Modal | |
| Toast | |

## Reduced motion

Honour `prefers-reduced-motion: reduce` — opacity only, no large movement.

## Do not

- Bounce on professional services
- Infinite parallax on copy
- Auto-playing loud stories as “brand”
