# Typography

Two families. A mono only if the product needs it (fintech, code, tickets).

## Families

| Role | Family | Weights | License |
|---|---|---|---|
| Display / headings | | | |
| Body | | | |
| Mono (optional) | | | |

## Stacks (for developers)

```css
--font-display: "[Heading]", "Iowan Old Style", "Palatino Linotype", serif;
--font-body: "[Body]", "Segoe UI", system-ui, sans-serif;
--font-mono: "[Mono]", ui-monospace, monospace;
```

## Scale

| Step | Desktop | Mobile | Weight | Line | Use |
|---|---|---|---|---|---|
| Display | 64 / 72 | 40 | | 1.0 | Hero |
| H1 | 48 | 32 | | 1.15 | Page title |
| H2 | 36 | 28 | | 1.2 | Section |
| H3 | 24 | 20 | | 1.3 | Card title |
| Body | 16–18 | 16 | | 1.5 | Reading |
| Small | 14 | 14 | | 1.45 | Meta |
| Caption | 12 | 12 | | 1.4 | Labels |
| Button | 14 | 14 | 600–700 | 1 | UI |

## Pairing rules

- Headlines: tracking `[ ]`, sentence vs all-caps
- Body: max measure ~65–75 characters
- Never mix a third display font “for fun” on a flyer

## Specimen to set in Figma

- One paragraph of real client copy (not lorem)
- A price
- A form label + button
- A long heading that wraps on mobile
