## Variants (required)

| Variant | File | Use |
|---|---|---|
| Primary horizontal | `*_logo_horizontal_color_on-light.svg` | Headers, docs, most web |
| Stacked | `*_logo_stacked_color_on-light.svg` | Square, profile, packaging front |
| Mark | `*_mark_color_on-clear.svg` | Favicon, app, wax seal, social when name is already there |
| Wordmark | `*_wordmark_color_on-light.svg` | When the mark is already on the page |

Each variant also ships: `white_on-dark`, `black_on-clear` (mono).

Optional: compact (tight kerning for small headers), badge, partnership lockup.

## Clear space

Unit `x` = height of the mark.
Keep `x` clear on all sides. Draw this in Figma; screenshot into guidelines.

## Minimum size

| Context | Lockup | Mark |
|---|---|---|
| Digital | 120px wide | 24px |
| Print | 35mm wide | 10mm |
| Favicon | — | 16px (test at 16) |

## Colour on backgrounds

| Background | Use |
|---|---|
| White / paper | Colour lockup |
| Dark ink | White lockup |
| Primary colour field | White or ink — pick one, document it |
| Photography | White or hold in a panel; never raw colour on a busy photo |

## Do not

- Stretch, outline, recolour off-palette, add shadows, rotate, rearrange mark + word, put in a random circle unless the badge variant exists.

## Partner / co-brand

Equal weight, clear space between, never lock into one new logo.
