# Studio approval (before the client sees “final”)

## Strategy

- [ ] Audience is a person, not “everyone”
- [ ] Positioning is one sentence
- [ ] Voice has 3 traits and 3 anti-traits
- [ ] Name, tagline, and category do not fight each other

## Logo

- [ ] Works at 24px (mark) and on a business card
- [ ] Horizontal, stacked, mark — all exist
- [ ] Colour, reverse, mono — all exist
- [ ] Clear space defined with a measurable unit (the mark’s height)
- [ ] Does not rely on a thin stroke that dies in print
- [ ] Favicon is the mark, not the full lockup
- [ ] No fake 3D, no random drop shadow, no stretched wordmark

## Colour

- [ ] Primary + accent + neutrals + semantic
- [ ] Body text on page background ≥ 4.5:1
- [ ] Primary on white documented (pass or “display only”)
- [ ] 60/30/10 usage written
- [ ] Tokens match the guidelines hex-for-hex

## Type

- [ ] Two families max (display + body) unless a mono is needed
- [ ] Scale from caption to H1
- [ ] License recorded
- [ ] Fallback stack in CSS

## Applications

- [ ] Only items in the sold tier exist
- [ ] Each application uses a real logo variant (not a new one)
- [ ] Social safe-zones respected
- [ ] Email signature is HTML, not a giant image
- [ ] File names match the convention

## Handover

- [ ] Manifest filled
- [ ] License page filled
- [ ] Walkthrough booked
- [ ] Exploration *not* in the client zip
