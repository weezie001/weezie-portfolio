# Assets

Drop **finals only** here. Source and rejects stay in `_source`.

```
06-assets/
├── logos/
│   ├── svg/
│   └── png/
├── colours/          swatch PNG + ASE/CLR if you make them
├── type/             licensed files OR a text file of license links — not both stolen
├── icons/            SVG, 24 grid
├── photography/      approved, licensed
├── patterns/
├── mockups/          presentation JPGs
└── _source/          Figma exports, audits, drafts — do not zip to client unless paid
```

Empty folders are intentional. They force the structure. Add a real file or leave the `.gitkeep`.

**Client zip** includes logos, colours, type (or links), icons, photography they own, patterns, mockups. It does **not** include `_source` unless they bought editable files.
