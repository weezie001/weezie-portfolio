# Designed applications included in v2

Open index.html at the root to customize these visually. The completed fictional sample is in `sample/ready-to-use` in the root kit, and the reusable blank files are in `editable-templates`.

From this folder, use `../sample/ready-to-use/` and `../editable-templates/`.
