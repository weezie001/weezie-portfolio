# Stationery (Standard+)

Spec every item. A pretty mockup without a print spec is a poster.

## Business card

| | |
|---|---|
| Size | 85 × 55 mm (or 3.5 × 2 in) |
| Bleed | 3 mm |
| Safe | 4 mm inside trim |
| Colour | CMYK + the spot/Pantone if sold |
| Sides | Front: mark + name. Back: role, phone, URL, QR optional |
| Paper | note stock (e.g. 350gsm uncoated) — recommend, do not guess their printer |
| Finish | none / foil / letterpress only if budgeted |

Files: `print-ready PDF` + `preview PNG`.

## Letterhead

A4 / Letter. Header lockup, footer legal line, generous type area. Supply PDF + Word/Google doc if they will type on it.

## Invoice / proposal header

Same as letterhead, plus a place for number, date, amount. Matches the website tokens.

## Envelope (optional)

Window vs no window. Logo placement that survives franking.

## Compliment slip

A6. One logo, one line, lots of paper.
