# Full CIP (only if sold)

Do not print the whole universe. Pick what they will produce in 12 months.

## Menu (choose 8–12)

**Place:** reception sign, room sign, wall graphic, wayfinding
**People:** ID badge, lanyard, polo, cap, apron
**Carry:** tote, folder, notebook
**Sell:** box, label, hang tag, bag
**Show:** roll-up 850×2000, backdrop, table cloth
**Move:** one vehicle diagram (left, right, rear)

Each item gets:

1. Flat artwork (print-ready)
2. One photoreal mockup for the presentation
3. Spec: size, material, print process, colours, exclusion zone

## Tech pack line (apparel)

Print area in mm, max colours, hex, placement from collar. Without this the printer invents.
