# Handover checklist

Build the zip from this list. Name it `[brand]_brand-kit_v1.zip`.

## Always (all tiers)

- [ ] Brand guidelines PDF (or HTML book + print CSS)
- [ ] Logo SVG pack (horizontal, stacked, mark, wordmark × colour/white/mono)
- [ ] Logo PNG pack (512 + 1024 for mark; 2x for lockups)
- [ ] Favicon set
- [ ] Colour page (hex RGB, CMYK if print)
- [ ] Type: files or license links + what they may install
- [ ] `tokens.css` + `design-tokens.json`
- [ ] Email signature HTML
- [ ] Social avatar
- [ ] This checklist + `FILE-MANIFEST.md` + `LICENSE-AND-USAGE.md`
- [ ] `CLIENT-WALKTHROUGH.md` agenda (they keep it)

## Standard adds

- [ ] Full voice + messaging PDF or section in guidelines
- [ ] Icon set SVG
- [ ] Card + letterhead print PDFs
- [ ] Social templates (1:1, 4:5, 9:16, one banner)
- [ ] Slide cover + inner
- [ ] OG image 1200×630

## Full CIP adds

- [ ] Chosen application artworks + mockups
- [ ] Spec sheets per item
- [ ] Phase 2 list

## Never in the zip

- [ ] 40 explorations
- [ ] Unlicensed fonts
- [ ] Competitor screenshots
- [ ] Your invoice internals
- [ ] `.fig` unless they paid for source

## After send

- [ ] Walkthrough done
- [ ] Access: Figma view link (optional)
- [ ] Website job: tokens copied into the repo, palette not re-sampled
