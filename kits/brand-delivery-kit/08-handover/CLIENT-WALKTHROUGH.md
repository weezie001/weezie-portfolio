# Client walkthrough (30–60 min)

Do not email a zip with “let me know if you have questions.” Sit with them.

## Agenda

1. **Platform in 3 minutes** — who it is for, personality, the one-line position.
2. **Logo family** — when to use horizontal vs stacked vs mark. Show a *wrong* example.
3. **Colour** — 60/30/10. Show the illegal combo you already know they will try.
4. **Type** — which font for headlines, which for WhatsApp they should not use (system is fine in chat).
5. **Files** — open the folder together. Point at SVG vs PNG. “SVG for print and web. PNG for WhatsApp.”
6. **Tokens** — if a developer is on the call, open `tokens.css`.
7. **Applications they bought** — card, email, social. Who will actually produce these.
8. **What happens if they need a van / packaging** — phase 2, not a favour.
9. **Edits** — what a revision is vs a new job.

## They should leave able to answer

- Which file goes on Instagram
- Which file goes to the sign maker
- Who to ask before someone “just changes the orange”

## Recording

Offer a Loom of this session. Put the link in the handover email.
