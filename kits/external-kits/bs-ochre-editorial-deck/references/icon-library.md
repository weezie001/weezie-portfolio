# Icon library

Use inline SVG icons with a 24 by 24 viewBox, currentColor strokes, rounded joins and no icon font. Decorative emoji and dingbat glyphs are prohibited.

## Curated paths

The examples use a directional arrow for the reading cue. Use the same stroke weight throughout a deck.

- Arrow right: M5 12h14M13 6l6 6-6 6
- Arrow left: M19 12H5M11 6l-6 6 6 6
- Circle: circle cx="12" cy="12" r="9"
- Check: M5 12l4 4L19 6
- Grid: M3 3h7v7H3zM14 3h7v7h-7zM3 14h7v7H3zM14 14h7v7h-7z

Lucide-compatible rendering convention: viewBox="0 0 24 24", fill="none", stroke="currentColor", stroke-width="1.8", stroke-linecap="round", stroke-linejoin="round". Use the paths as simple geometric primitives, never brand marks.

LobeHub monochrome model marks may be used only for a real integration with a visible label. They are unnecessary in this deck and must not appear as fictional logos or decoration. Do not include a logo library unless that integration is actually needed.
